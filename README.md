# دفتر المحاسبة — Smart Accountant

تطبيق Flutter عربي RTL لإدارة الحسابات والقيود اليومية والأطراف والمخزون وفواتير البيع والشراء. هذه النسخة نموذج أولي وظيفي محلي (offline-first) وليست منتجًا ماليًا معتمدًا أو جاهزًا لتخزين بيانات حقيقية قبل استكمال ضوابط الأمن ��الاختبارات والامتثال المحلي.

## الوظائف الموجودة

- دليل حسابات ابتدائي: أصول، خصوم، حقوق ملكية، إيرادات، ومصروفات.
- ترحيل قيد يدوي متوازن باستخدام مبالغ صحيحة بوحدات العملة الصغرى.
- إضافة العملاء والموردين.
- إدارة أصناف المخزون والرصيد الافتتاحي.
- فواتير بيع وشراء أحادية الصنف؛ تحدّث المخزون وتنشئ قيدًا تلقائيًا ضمن معاملة SQLite ذرية.
- ميزان مراجعة، لوحة رئيسية، وعرض عربي RTL مع تبديل الوضع الداكن.
- تخزين محلي دون الحاجة إلى اتصال بالإنترنت.

## التشغيل

المستودع يحتوي تطبيق Flutter قائمًا، لذا لا تنفذ `flutter create` فوقه. ثبّت إصدار Flutter المتوافق مع `pubspec.yaml` ثم من جذر المشروع:

```bash
flutter doctor
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء Android تجريبي:

```bash
flutter build apk --debug
```

## دقة الحساب

الأموال تخزن كأعداد صحيحة في أصغر وحدة للعملة (minor units)، والكميات بوحدات الألف لتجنب التخزين العشري الثنائي. عملة العرض الحالية ثابتة إلى SAR في الواجهة؛ يجب إضافة إعداد عملة ودقة منازلها قبل دعم عملات متعددة. لا توجد ضريبة مطبقة تلقائيًا، على الرغم من وجود حقل ضريبي بالفاتورة؛ يجب ضبط القواعد وفق الدولة وتاريخ سريانها ومراجعتها محاسبيًا.

## قبل الاستخدام الإنتاجي

هذه النسخة لا تدّعي الاعتماد المالي أو الأمان الإنتاجي. قبل إدخال بيانات فعلية، يلزم على الأقل:

1. تشفير SQLite عبر حل SQLCipher موثوق ومختبر على Android وiOS، وإدارة المفتاح في Keystore/Keychain.
2. مصادقة محلية اختيارية، وسياسة قفل واستعادة، ونسخ احتياطي مشفر مع اختبار الاستعادة.
3. مزامنة خادمية مع عزل المؤسسات والصلاحيات وسجل تدقيق وحل تعارضات؛ لا تُضمّن أسرار الخادم في التطبيق.
4. مسارات تعديل/إلغاء آمنة بقيود عكسية، وسندات قبض وصرف وتسويات جزئية.
5. دعم الضرائب والإشعارات والفواتير الإلكترونية حسب الاختصاص القانوني.
6. اختبارات وحدات وتكامل للمحاسبة والمخزون، واختبار ترحيل قاعدة البيانات للأجهزة الحالية، ومراجعة مختص محاسبي.
7. اختبار فعلي عبر `flutter analyze`, `flutter test` وبناء Android/iOS في بيئة Flutter؛ لم تُشغّل هذه الأوامر في جلسة GitHub هذه.

## ملاحظة بشأن قاعدة البيانات الحالية

التطبيق الجديد يستخدم ملف قاعدة بيانات مستقلًا باسم `daftar_accounting.db` ولا يحذف قاعدة `maqani.db` السابقة. المخطط الأولي ينشأ عند تشغيله على جهاز جديد. عند توزيع تحديث لاحق، يجب إضافة migrations مرقّمة واختبارها، وعدم حذف بيانات المستخدمين.
